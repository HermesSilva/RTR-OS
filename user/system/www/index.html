Overall state: Failure if a process was terminated by a fault; Warning if, since the previous reading, there was a limit overrun, an unfinished activation, a skipped period, an unhandled interrupt or a drop, or if the system started with its limits scaled down; Normal otherwise. All times come from the system counter. The window of each measurement is the interval between two readings of this page.

Manifest text, as it will be written to the card

Applications come as .rpkg packages: "Install app" unpacks one onto the card, and its programs then appear in the program list. The installation is described by MANIFEST.TXT on the SD card and is read once at boot. Saving writes the file and reboots the board; the changes take effect after the reboot. The ? next to each field explains it.
